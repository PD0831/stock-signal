# MVS 选股与仓位规则

本项目现在只生成一个 NASDAQ-100 账户级组合。S&P 500 数据继续用于判断市场宽度和风险状态，但不再生成另一套重复的买入清单。

## 先判断是否可以买

只有 MVS 市场状态为 `long` 时才持有股票。其他状态全部空仓，股票仓位为 0%，账户净值 100% 保留现金。当前生产快照（2026-09-11 14:10:58 UTC）处于 Phase E、`short_watch`，所以当前操作是：不买任何股票。

## 普通 Long 怎么买

组合由两条资金腿组成，并把总名义暴露设为账户净值的 112.5%。如果账户净值为 100,000 美元，目标持仓总额为 112,500 美元，超出净值的 12,500 美元属于融资暴露。

第一条是流动性腿。按过去 63 个交易日的平均每日成交额（ADV63）对 NASDAQ-100 成分股排序，买入前三名，每只占账户净值的 18.75%，即每只 18,750 美元。

第二条是趋势腿。先取 ADV63 排名前 15 的不同公司，再按“最新收盘价相对 EMA200 的距离”从高到低排序，选前三名。这三只分别占账户净值的 33.75%、11.25% 和 11.25%，即 33,750、11,250 和 11,250 美元。

同一只股票如果同时进入两条腿，系统会把权重相加。例如一只股票既是 ADV 前三，又是 EMA200 距离第一名，它的账户目标权重为 18.75% + 33.75% = 52.50%。页面只显示一行合并后的持仓。

## Phase C 牛市回调怎么买

Phase C 暂时作为已回测 `Dip Long` 事件的实时代理。流动性腿保持不变，第二条腿改为 ADV63 前十名等权。

因此，ADV 排名前三的股票各占账户净值的 24.375%：18.75% 来自流动性腿，5.625% 来自 Dip 腿。ADV 排名第 4 至第 10 的股票各占 5.625%。以 100,000 美元账户计算，前三名各买 24,375 美元，第 4 至第 10 名各买 5,625 美元，总名义持仓仍为 112,500 美元。

## 股数怎么计算

页面默认以 100,000 美元账户净值计算，也可以直接修改账户金额。每只股票的计划金额等于账户净值乘以目标权重；整股数量等于计划金额除以最新收盘价后向下取整。剩余不足一股的金额保留为现金。

普通 Long 在信号后的下一个开盘执行；Phase C 的 Dip 代理按当日收盘价计算；月度复核和 Risk Off 都在下一个开盘处理。快照会同时显示每只股票来自哪条资金腿、合并权重、计划金额、整股数量、最新价、EMA200 距离和 ADV 排名。
