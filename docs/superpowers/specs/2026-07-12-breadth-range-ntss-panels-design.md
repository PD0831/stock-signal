# 15 分钟宽度范围选择与 NTSS 双面板设计

## 目标

扩展 MVS 15 分钟市场宽度页，使用户能够在 `1D / 5D / 20D / 3M` 之间切换历史范围，并在与 Strong、Breakdown 同步的独立面板中观察 NTSS。默认范围为 5D。

## 已确认的交互

- 范围：1D、5D、20D、3M。
- 默认：5D。
- 图表：上下双面板，共享时间轴。
- 上面板：Strong 与 Breakdown，固定 0–100% 刻度。
- 下面板：NTSS，独立动态刻度，并显示零轴。
- 正 NTSS 区域代表相对安全，负 NTSS 区域代表恐慌/风险。
- 最近一次状态切换标记随所选范围过滤。
- 用户选择保存在浏览器本地，下次打开继续使用。

## 数据架构

GitHub Actions 继续负责行情下载与计算。每次刷新时：

1. 读取已有 `data/breadth_15m.json`。
2. 下载行情源当前可提供的 15 分钟记录。
3. 将新旧 aggregate records 按带时区时间戳合并。
4. 相同时间戳保留最新计算结果。
5. 按时间升序排序。
6. 删除生成时间之前超过 3 个自然月的记录。
7. 重新计算或校验最新状态切换信息，然后与 dashboard snapshot 原子发布。

Render 仍只读取聚合 JSON，不下载行情、不计算全市场 DataFrame。预计 3 个月约 1,500–1,700 根美股 15 分钟记录，JSON 仍远低于 512MB 内存限制。

行情源可能无法一次返回完整 3 个月的 15 分钟数据。因此 3M 页面必须显示实际覆盖起止日期；历史会随着 Action 运行逐步累积，不能假装已有完整 3 个月。

## 范围定义

- `1D`：最新一个有数据的交易日。
- `5D`：最新五个不同的交易日，不用自然日近似。
- `20D`：最新二十个不同的交易日。
- `3M`：从最新记录向前推三个自然月，并受实际留存数据限制。

所有范围过滤均在浏览器端针对聚合 records 完成，不触发额外 API 或服务器计算。

## 图表设计

### 共享结构

- 两个 SVG 面板共享相同的横向时间位置。
- 跨夜与周末不按真实空白时长拉开，而按记录序号等距绘制；时间标签显示交易日和时刻。
- 悬停或键盘聚焦时，两面板共享同一根竖向游标，并显示该记录的时间、Strong、Breakdown、NTSS 与阶段。
- 状态切换只标注当前范围内的变化。

### Strong / Breakdown 面板

- Strong 使用绿色。
- Breakdown 使用红色。
- Y 轴固定为 0–100%。
- 缺失任一指标的记录不伪造为零；折线在缺口处断开。

### NTSS 面板

- 使用独立动态 Y 轴，同时必须包含零值。
- 零轴清晰可见。
- 正值区域使用低饱和绿色背景，负值区域使用低饱和红色背景。
- 缺失 NTSS 的记录形成缺口，不以零替代。
- 当前 NTSS 状态徽章与顶部卡片继续保留，但必须使用生产端权威状态字段。

## 状态与降级

- 数据不足：对应面板显示明确提示，不绘制误导性折线。
- 选择范围超过实际覆盖：显示可用数据，并标明“实际覆盖 X 至 Y”。
- 无 NTSS：宽度面板仍可用，NTSS 面板显示“该范围暂无 NTSS 数据”。
- 过期快照：继续展示历史，并保留现有 stale 标记。
- 加载、不可用、市场关闭状态必须清除旧悬停内容和游标。
- 无效、重复或无时区时间戳在生产或 API 校验层拒绝；浏览器渲染层仍防御性去重排序。

## 测试与验收

### 生产端

- 合并已有与新 records。
- 重复时间戳覆盖规则。
- 严格时间排序。
- 三个月裁剪边界。
- 首次运行无旧文件。
- 旧文件损坏时不覆盖最后一份有效快照。
- NTSS 字段与状态语义保留。

### 浏览器端

- 1D/5D/20D 按交易日数量过滤。
- 3M 按自然月过滤。
- 默认 5D 与 localStorage 持久化。
- 两面板共享 X 坐标与游标。
- NTSS 独立刻度始终包含零。
- 缺失 Strong、Breakdown 或 NTSS 不绘制为零。
- 状态切换随范围更新。
- 加载/错误/关闭状态完整重置。
- 移动端范围按钮、双面板和研究折叠区可用。

### 资源验收

- 使用 3 个月最大预期 records 重复请求和渲染。
- Render 单 worker RSS 仍显著低于 256MB 本地目标。
- API 响应与 JSON 大小记录在部署验证中。
- 所有行情外联仍被限制在 GitHub Actions，Render 网络守卫测试继续通过。

## 非目标

- 不在本次修改中改变 MVS 阶段或交易动作定义。
- 不在 Render 内进行历史补抓或指标计算。
- 不增加 Plotly 等大型前端图表依赖。
- 不把 3M 选项伪装成数据源已经提供完整三个月历史。
